# CodeIgniter 4 Web Application

This is a web-based application developed using **CodeIgniter 4**, **PHP**, and **MySQL**. The project follows the MVC architecture of CodeIgniter and uses environment-based configuration for managing the application URL, database connection, and development settings.

The application is designed to run locally using XAMPP/WAMP with MySQL database support. It provides a clean project structure, secure configuration handling, and a scalable foundation for building dynamic PHP web applications.

## Project Description

This project is built on the CodeIgniter 4 framework. It uses PHP for server-side development and MySQL for database management. The application is configured with a local base URL and MySQLi database driver.

The project can be used as a starting point for developing a complete dynamic website or management system using CodeIgniter 4.

## Features

- CodeIgniter 4 MVC architecture
- PHP 8.1+ support
- MySQL database connectivity
- Environment-based configuration using `.env`
- Local development setup
- Composer dependency management
- Secure front controller structure
- Clean and scalable project structure
